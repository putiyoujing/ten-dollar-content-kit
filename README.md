# $10 Content Rescue Kit

A tiny public storefront for a fixed-price content micro-service.

## Offer

For $10, one customer gets:

- 10 hooks or titles
- 3 cover or thumbnail lines
- 1 ready-to-post caption/body draft
- 5 comment prompts or reply starters

## Order Flow

1. Customer opens a GitHub Issue using the order template.
2. Payment method is confirmed in the issue thread before work begins.
3. Delivery is posted as a Markdown file or issue comment within 24 hours.
